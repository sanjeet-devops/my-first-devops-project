# My DevOps Learning Journey

### 1. Git Basic Commands
- `git checkout <commit-id>` : Purane commit par jaane ke liye (Detached HEAD state).
- `git switch -c <branch-name>` : Nayi branch banane aur usme switch karne ke liye (Jaise: `sanjeet-devops`).
- `git branch` : Saari branches ki list dekhne ke liye.
- `git status` : Dekhne ke liye ki kaunsi files change hui hain.
- `git add .` : Saari files ko save karne ke liye ready (Stage) karna.
- `git commit -m "message"` : Changes ko permanent save karna.
- `git push origin <branch-name>` : Local kaam ko GitHub par upload karna.
- `git remote add origin <url>` : Apne computer ko GitHub repository se jodne ke liye.

### 2. Linux Basics (Jo aage kaam aayengi)
- `ls` : Folder ki saari files dekhne ke liye.
- `cd` : Ek folder se dusre folder mein jaane ke liye.
- `pwd` : Ye dekhne ke liye ki abhi aap kis folder mein ho.
- `mkdir` : Naya folder banane ke liye.
- `touch <file-name>` : Nayi khali file banane ke liye.
touch sail-report.txt: is se nyi file .txt name ki ban gyi
ls -l sail-report.txt: is se nyi jo bni hai uska permission dekhne keliye.
chmod 444 sail-report.txt: is se file read only me hojata haiisme edit nhi kar sakte.
